# 게이브 운영과 시험

26.3 Paper 서버(바닐라 26.3 클라 접속) 협동 웨이브 미니게임. 처음 하는 사람, 운영자용 짧은 안내는 `docs/게임안내.md`. 게임 규칙과 55종은 `docs/게이브도감.md`(기계용 `data/bestiary.json`), 작업자 계약(이름, 포트, 패키지, 파일 주인)은 `docs/구조.md`, 좀비런에서 가져온 것의 지도는 `docs/reuse/*.md`.

## 빌드

한 번에: `python -X utf8 tools/build_all.py` (명령은 모두 `gave/` 에서). 아래 1~4 를 이 순서로 돌린다: props(소품 층) → gcb(다른 서버에서 옮긴 총 셋, `ref/gcb/extracted` 가 없으면 건너뜀) → pack_src → shop_ui(상점 화면) → fx → gabe → director(감독 소리) → far(먼 저음 층) → bgm(배경 음악) → hud → hud_promote(HudSpec 을 코드로) → pack(`build/Gave-pack.zip` 과 `build/Gave-sound.zip`) → shaders(셰이더 검사) → layer(몹 층 검사) → real(진짜 트리 jar `build/real/Gave.jar`) → parity(키트와 Look 부호 대조, 그 jar 로) → plugin. 단계마다 실패하면 멈추고 그 단계 이름과 기록 끝 30줄을 보여 준다(전체 기록 `build/build_all/<단계>.out`). 고친 뒤 `--from <단계>` 로 거기서부터, `--skip props,bgm` 으로 빼고, `--list` 로 단계와 명령을 본다. 다른 사람이 게임 안 시험을 돌리는 중에도 돌려도 되지만 hud_promote 가 진짜 `HudSpec.java` 를 바꾸므로 줄 서 있는 시험은 `ingame.py` 가 잠금을 얻은 뒤 jar 를 다시 컴파일한다.

단계별로 돌릴 때도 순서를 지킨다.

1. 소품 층(총, 수류탄, 탄약통, 그 소리): 바꿀 때만 `python -X utf8 tools/props/build_props.py` → `build/props/pack_layer/`, `tools/props.json`(이름공간 gave). 검사 `python -X utf8 tools/props/check_pack.py` (오류 0 이어야 함, 소리 출처 흔적 경고는 아래 '배포할 때' 참고)
2. 팩 바탕
   - `python -X utf8 tools/make_pack_src.py` (바닐라 HUD 그림 투명, `gave:empty`, pack.mcmeta)
   - `python -X utf8 tools/make_fx.py` (사격, 폭발 셰이더 연출, core/item 고리. `pack_fx/*.glsl` 을 모두 include 로 옮김)
   - `python -X utf8 tools/make_gabe.py [--only g05] [--preview]` (게이브 몹 층 `build/gabe/pack_layer/`). 종마다 요약 줄 `모델, 상태, 요소, 틴트 칸, 면 [모델:상태 면 수], 텍스처, 소리, 덮개`(상태 모델 하나 면 400 한도, 넘으면 굽기 실패). 검사 `python -X utf8 tools/gabe/tests/check_layer.py`, 키트와 `Look.java` 부호 대조 `python -X utf8 tools/gabe/tests/look_parity.py`(키트나 Look 을 고칠 때만). 프레임 측정 `tools/scenarios/pack_fps.json` + 백그라운드 `tools/gabe/tests/f3_helper.py`. 종 작성법 `docs/모듈/종작성법.md`, 모듈 API 모음 `docs/모듈/API.md`
   - 상점 그림을 바꿀 때만 `python -X utf8 tools/make_shop_icons.py`
   - 상점 화면(상자 창의 어두운 판, 값 숫자, 풍선 도움말 틀)을 바꿀 때만 `python -X utf8 tools/make_shop_ui.py` (`pack_src` 의 상점 자산과 `assets/gave/shop_ui.json`. `make_pack_src.py` 뒤에 돌린다)
   - 감독 소리(떼 소리 층 `director.horde`, `director.chorus`, 심장 박동 `director.heart`)를 바꿀 때만 `python -X utf8 tools/make_director_sounds.py` (pack_src/assets/gave 의 sounds.json, sounds/director, lang 에 director 키만 고쳐 씀. 키트는 안 거침)
   - 먼 저음 층(`far.*`)을 바꿀 때만 `python -X utf8 tools/make_far_sounds.py` (pack_src/assets/gave 의 sounds.json, sounds/far, lang 에 far 키만 고쳐 씀. 감독 소리 다음에: 받은 허밍 가공 변형이 감독 소리 파일을 풂). 보탠 크리처 소리 전체의 자가 점검은 `--check`. 가까운 공용 사건(`gabe.cry_*` 등)과 종 별칭은 게이브 몹 층(make_gabe)이 굽는다(`tools/gabe/flesh.py`, `data/gabe_voice.json`, 표를 고치면 종 전체를 다시 굽기)

### 팩 둘(모습 팩, 소리 팩)

- 모습 팩 `Gave-pack.zip`: 모델, 텍스처, 셰이더, 글꼴, 언어(자막 글 포함), 아이템 정의, `music.json`, `gabe_looks.json` 같은 데이터, `pack.mcmeta`(설명 '게이브 모습'), `CREDITS.txt` 와 라이선스 전문. 플러그인이 읽는 `music.json`(`Music`), `gabe_looks.json`(`Look`)은 여기 있다(`PackServer.bytes()` 는 모습 팩).
- 소리 팩 `Gave-sound.zip`: 모든 이름공간의 `assets/<이름공간>/sounds.json` 과 `assets/<이름공간>/sounds/` 아래 파일 전부(ogg 는 어디 있든 소리 팩), 자기 `pack.mcmeta`(설명 '게이브 소리'), 같은 `CREDITS.txt` 와 라이선스 전문. 두 팩에 같은 경로는 맨 위 파일(`pack.mcmeta`, `CREDITS.txt`, `LICENSE-*.txt`)뿐이다. 소리를 더해도(락 브금, 받은 효과음, 새 게이브 소리) 모습 팩은 그대로라 바뀐 팩만 다시 받는다.
- 플러그인(`PackServer`)은 `gave.packDir`(없으면 `build/`)에서 두 팩을 읽고, `Gave-sound.zip` 이 있으면 한 요청에 모습 다음 소리로(아이디 `gave:main`, `gave:sound`) 보낸다. 없으면 `Gave-pack.zip` 하나만(소리까지 든 옛 꼴의 팩도 그대로 돈다). 이 PC 주소는 `/pack.zip`, `/sound.zip`. 소리 사건 목록(`Props`)은 두 팩의 `assets/gave/sounds.json` 을 합쳐 읽는다. 접속 전 구성 단계에서 두 팩이 모두 끝날 때까지 기다리고, 하나라도 못 붙으면(거절 빼고) 들어온 뒤 2초에 한 번만 다시 보낸다(깃허브에서 못 받은 팩은 그때 이 PC 주소로. 그것도 못 붙으면 팩 없이 논다). `/gave 팩` 은 두 팩을 뒤에서(주 스레드 밖) 다시 읽고, `gave.packRepo` 가 있으면 바뀐 팩이 깃허브 릴리스에 올라가 있는지까지 확인한 뒤에 바꿔 끼워 모두에게 다시 보낸다. 확인이 끝날 때까지는 읽기 전 팩과 주소를 그대로 내보내고, 파일을 못 읽었거나 깃허브에서 확인되지 않은 팩이 있으면 아무것도 바꾸지 않고 까닭만 알린다(요청이 replace 라 있던 팩부터 내려가므로, 이 PC 주소가 밖에서 안 열린 실서버에서 모두의 팩이 내려가는 것을 막음). sha1 이 그대로인 팩은 확인된 깃허브 주소를 그대로 쓴다. `/gave 팩 강제` 는 확인되지 않은 팩도 이 PC 포트로 내보내게 바꿔 끼운다(그 포트가 밖에서 열려 있을 때만).
- 팩을 받게 할 주소: `gave.packRepo`(깃허브 저장소, 릴리스 `pack-<sha1 앞 12자리>`) 말고도 `gave.packUrl`(모습 팩 주소 하나, 예: 깃허브 브랜치의 커밋 고정 raw 주소)을 줄 수 있다. 둘 다 있으면 `gave.packUrl` 이 먼저다. 켤 때(와 `/gave 팩`) 그 주소의 파일을 받아 sha1 이 이 PC 의 모습 팩과 같을 때만 그 주소를 보내고, 다르거나 못 받으면 이 PC 포트로 보낸다. 소리 팩이 따로 있으면 그 팩은 `gave.packRepo` 가 있을 때만 깃허브로, 아니면 이 PC 포트로.
- 기본값: `build/` 로 묶을 때(`GV_PACK_OUT` 없음, `build_all.py` 도)는 늘 둘로 나눈다. 시험 팩(`GV_PACK_OUT`, `ingame.py`)은 `GV_PACK_SPLIT=1` 일 때만 나누고 아니면 예전처럼 하나로 묶으며, 그때 옆에 남은 옛 `Gave-sound.zip` 은 지운다(남으면 서버가 소리를 두 번 보냄). `GV_PACK_SPLIT=0` 이면 어디로 묶든 하나로.
- **시험 팩도 기본으로 나누려면(다른 작업이 끝난 뒤 켬): `tools/build_pack.py` 의 `SPLIT_TEST = False` 를 `True` 로 바꾼다.**
- 시험: `GV_PACK_SPLIT=1 python -X utf8 tools/ingame.py --name <영역> --scenario ...` 이면 `build/<영역>/` 에 두 팩을 만들고 서버가 둘 다 보낸다. 서버 기록에 팩마다 `팩 상태 <이름> 모습|소리 <상태> (접속 전)` 한 줄씩과, 두 팩이 모두 끝나면 도구가 읽는 `팩 상태 <이름> <상태> (접속 전, 팩 2개)` 한 줄(모두 붙으면 SUCCESSFULLY_LOADED, 아니면 실패한 상태)이 남는다. 팩 대본 `tools/scenarios/pack_split_a.json`.

셰이더를 고쳤으면 `python ~/.claude/skills/minecraft-shader/scripts/check_shaders.py pack_src --mc 26.3` 이 0 오류여야 한다(깨진 코어 셰이더는 팩 전체를 내림). `make_hud.py` 는 임시 사본에서 이 검사를 먼저 돌리고 통과할 때만 쓰지만 `make_fx.py` 는 검사하지 않는다. 검사 통과가 화면이 맞다는 뜻은 아니니 게임에서 F3+T 와 `latest.log` 로도 본다.

소리 높이 계약: 서버는 켤 때와 `/gave 팩` 때 내보내는 팩 zip(둘로 나눴으면 두 팩을 합쳐, 보통은 소리 팩)의 `assets/gave/sounds.json` 을 읽어 거기 있는 사건만 모드 소리로 울리고(pitch 로는 흔들림만 보냄) 없는 사건은 바닐라 대체 소리로 울린다. 모드 소리 높이는 `tools/props/build_more.py` `PITCH` 에만 적는다. `attenuation_distance` 는 Java 가 소리를 보내는 반경과 맞춘다(`GUN_FIRE_RANGE`, `RANGE`).

인벤토리 그림: 좀비런은 총을 gui 자리에서 숨겼지만 게이브는 상자 상점과 인벤토리에서 총, 수류탄이 보인다(`build_pack.py` `GUI_HIDE` 가 비어 있음). 바닐라 핫바 틀은 투명이라 핫바 칸의 아이템 그림은 화면 아래에 틀 없이 그려진다. 숨길 아이템이 생기면 `GUI_HIDE` 에 키를 더한다.

### 한국어 글귀(HUD)

- 글귀는 `data/phrases/*.json`(`{키: 글}`, 파일 이름은 묶음 이름일 뿐: `common.json`, `G01.json` ...)과 `data/bestiary.json` 종 이름(키 `name_g01` .. `name_g55`)에서 `make_hud.py` 가 모아 Galmuri11 Bold 로 미리 그린다. 글귀 파일이 종 이름 키를 다시 적으면 그 글을 쓰고, 글귀 파일끼리 같은 키는 빌드를 멈춘다.
- 키는 소문자, 숫자, `_`, `-` 만. 그림 이름 = 키. 높이 9 GUI(텍셀 1 = 3/4 GUI, 기준선 아래 잉크가 있으면 12 GUI), ascent 8, 오른쪽 아래 1 화소 그림자를 구워 넣는다. 그림이 240 텍셀(180 GUI)보다 넓으면 `키.2`, `키.3` 조각으로 나눈다.
- Java 는 `HudSpec.PHRASES`(키), `PHRASE_PARTS`(조각 그림 이름, 쉼표로 이음), `PHRASE_X`(조각 x, GUI), `PHRASE_W`(폭, GUI), `PHRASE_TEXT`(글, 시험 표시용)로 찾는다. 글귀를 더하거나 바꾸면 `make_hud.py` 와 `compile_wip.py --name hud --promote`, `build_pack.py` 를 다시 돌린다.
- 가운데점(U+00B7)이 든 글귀는 빌드를 멈춘다. 설명 글 벽은 쓰지 않는다(배치와 강조로 뜻을 전함).
- 그림 글리프는 U+E100 부터 768 장까지(넘으면 빌드가 멈춤). 미리보기 `python -X utf8 tools/make_hud.py --preview build/hud_preview.png`, 배치 그림 `--mock build/hud_mock.png --no-check` (끝나면 지운다).

## 서버

- 서버 실행 옵션에 `-Dspark.backgroundProfiler=false` 가 들어 있다(`tools/test_server.sh`, 실서버 bat `tools/make_live.py`). Paper 에 든 spark 의 배경 프로파일러가 Windows 에서 100~350ms 틱 멈춤을 만들었다. 실서버 bat 는 `python -X utf8 tools/make_live.py` 를 다시 돌려야 바뀐다.
- 켜기, 끄기: `bash tools/test_server.sh start`, `bash tools/test_server.sh stop`, 명령은 `bash tools/test_server.sh rcon "gave 상태"`. 서버를 띄우는 스크립트의 출력은 파이프로 받지 말고 파일로 받는다(Windows 파이프 막힘).
- 포트: 게임 26200, RCON 26201(비밀번호 `gave-dev`), 팩 8290(플러그인이 직접 내보냄, 모습 팩 `/pack.zip`, 소리 팩 `/sound.zip`, 접속 전 구성 단계에서 보내고 모두 적용될 때까지 기다림). 슬롯 N(`GV_SLOT=N`)은 `runtime-N/`(처음 켤 때 `runtime/` 을 복사, 약 220 MB), 게임 26200+10N, RCON 26201+10N, 팩 8290+N.
- 이 PC 의 다른 세션 서버(25940/25941, 26000~26099, 26100/26101, 8215, 8250~8259, 8270 등)는 끄거나 건드리지 않는다. `test_server.sh stop` 은 자기가 띄운 서버(기록한 pid 와 생성 시각이 맞을 때)만 끈다.
- 전장은 구조물 없는 황야와 중앙 원이다(생성기 `PlazaGen`, 배치 `Plaza`, `docs/모듈/감독맵.md`). 생성기를 고쳤으면 서버를 끈 채로 `runtime/gave_plaza` 를 지우면 다음 켤 때 새로 만든다(시험은 `--fresh-world`). 팩을 먼저 만든 뒤에 월드를 만든다. 사람은 중앙에서 48블록(R_ROAM)에서 피해 없이 되밀린다(바닐라 월드 경계는 600블록 밖이라 안 보임).
- 접속: 26.3 클라로 `127.0.0.1:26200`. 팩은 저절로 받는다.

## 명령(`/gave`, 다른 이름 `/게이브`, 권한 `gave.op`)

| 명령 | 하는 일 |
|---|---|
| `/gave 시작` | 판 시작(준비 10초 뒤 1웨이브) |
| `/gave 중지` | 판을 멈추고 대기실로 |
| `/gave 상태` | `state=`, `wave=`, `mobs=`, `alive=` 등(시험 대본 `until` 이 읽음) |
| `/gave 팩` | 팩 파일을 뒤에서 다시 읽고, 깃허브 확인(`gave.packRepo`)까지 끝난 뒤에 모두에게 다시 보냄. 못 읽었거나 깃허브에 없는 팩이 있으면 바꾸지 않음(`/gave 팩 강제` 는 이 PC 포트로라도 보냄) |
| `/gave 자동 on` 또는 `off` | 대기실에 minPlayers 명이 차면 30초 뒤 자동 시작. 인자 없이 치면 지금 값만 알림. 설정에 저장하지 않음(다시 켜면 `autoStart` 값) |
| `/gave 원정 on` 또는 `off` | 원정(트럭, 길 투표, 이동, 발사장)을 켜고 끔. 대기실이면 바로(트럭과 소품, 빛 블록이 서거나 사라지고 땅을 그 방식의 바탕으로 다시 칠함), 판이 도는 중이면 그 판은 그대로 두고 대기실로 돌아간 첫 틱에 바뀜(`/gave 상태` 의 `trip=on ... next=off`). 인자 없이 치면 지금 값만 알림. 설정 `trip.enabled` 에 저장(다시 켜도 남음) |
| `/gave 최대인원 <수>`(또는 `/maxplayer <수>`) | 서버 최대 인원을 바로 바꾸고 `server.properties` 의 `max-players` 줄도 고쳐 다시 켜도 남김(1~1000). 수 없이 치면 지금 값 |
| `/gave 웨이브 <n>` | n 웨이브(1~999)로 바로 감(대기실이면 판부터 시작) |
| `/gave 다시하기` | 진 판이 끝나는 동안(투표가 열린 40초) 투표 없이 바로 다시 하기: 모두 세우고 20초 준비 뒤 진 라운드부터(총, 증강, 강화, 돈, 트럭 부품 그대로). 보통은 채팅의 [여기를 누르기] 투표(판에 든 접속자의 과반, 나간 사람은 안 셈). `Game.retry`, `startRetry` |
| `/gave 소환 <종> [수] [거리] [이름]` | 그 사람(없으면 보낸 사람, 없으면 중앙 원 가운데) 앞에 게이브를 놓음 |
| `/gave 시험 <행동> <이름> [수...]` | 시험 훅(모듈마다 `test(Player, String[])`) |

밸런스: 숫자는 `Director.Tune`(웨이브 총량, 동시 수, 인원 비례, 체력, 피해, 보상, 소리 층, 판 끝), 종 체력, 점수, 보상은 `tools/gen_species.py` TUNE(`--out` 으로 wip 에 생성 가능), 상점 값은 `Shop.Ware`. 바꾸기 전에 모의로 곡선을 본다: `python -X utf8 tools/balance_sim.py [--seeds 12] [--people 1,3,5,10,20,30] [--skill 0.6] [--table] [--set 이름=값,...] [--probe 웨이브:총:초[:강화],...]`(인원별 도달 웨이브 중앙값, 웨이브별 걸린 초, 쓰러짐, 남은 체력, 번 돈, 화력. `--probe` 는 게임 안 봇 시험과 맞대는 한 웨이브. 게임 안 봇 = 명중 0.7 쯤). 근거와 표는 `docs/모듈/떼와절망.md` '결과'.

설정 `plugins/Gave/config.yml`: `autoStart`, `minPlayers`(1 이상: 0 이하로 적어도 1 로 읽음), `prepSeconds`, `breakSeconds`, `latentCap`(판 전체 동시 잠복 감염, 기본 4), `cage`(옛 대기실 방과 게이브 우리, 기본 false: 대기실은 중앙 원. 켜면 새 월드부터 방이 지어짐), `crates.breakable`(진짜 보급 상자가 총 직격에 부서지나, 기본 false), `dex.quickKey`(도감 빠른 키 데이터팩을 까나, 기본 true), `moneyMul`(사람이 버는 돈 배율, 기본 1: 행사용. 2026-11-14 돈 구조가 옛 1.7 을 바탕 값에 녹였다. 옛 설정 파일에 `assistMul` 이나 `roundMoneyMul` 이 남아 있으면 켤 때 한 번 moneyMul 을 1 로 돌리고 두 키를 지워 저장하고 기록에 `[돈] 옛 돈 설정을 옮김` 을 남긴다). 감독 밸런스 숫자는 `Director.Tune`(켠 채 `/gave 시험 균형 x [이름 [값]]`).

래그돌 사체 설정(같은 파일 `ragdoll.*`, 명세 `docs/모듈/래그돌.md`): `enabled`(끄면 예전 납작 사체), `active` 10(물리 단계의 구), `activeDisplays` 50, `cheap` 150(값싼 단계에서 날아가는 조각: 넘치는 죽음만 납작), `settled` 120(굳은 사체), `pile`(사체가 쌓임), `faceUp`(얼굴이 깔리면 굴러 넘어가 눕기), `settleSeconds` 12, `memberSeconds` 4(떼 마리), `rods` 4, `kick`, `gravity`, `bounce`, `friction`. 이미 있는 config.yml 에 키가 없으면 jar 안 기본값을 쓴다. 켠 채 바꾸기 `/gave 시험 래그돌값 x <키> <값>`, 지금 수 `/gave 시험 래그돌 x`. 멀리 보이기: 몸 디스플레이 view range 는 1.6(102블록) 아래로 내려가지 않고, 서버 추적 거리는 `runtime/spigot.yml` entity-tracking-range.display 128, view-distance 10 그대로(2026-11-11 확인, runtime 설정은 바꾸지 않음).

배경 음악 설정(같은 파일, 명세 `docs/모듈/브금.md`): `music`(false 면 아무것도 안 틂), `musicVolume` 0.7(0..1), `musicCategory` VOICE(기본: 클라 설정 '음성/내레이터' 막대로 줄임, 2026-11-12 사용자. MUSIC 이면 '음악' 막대), `musicLog`(곡을 틀 때마다 서버 기록 `[음악] t=틱 이름 상태 곡 w= tier= ten=`). 웨이브 단계를 고를 때는 늘 `[음악] 웨이브 n 단계 ..` 한 줄. 바닐라 배경 음악은 황야 바이옴(창백한 정원, 26.3 환경 속성 `audio/background_music` 비어 있음, `audio/music_volume` 0)이 끄고, 플러그인이 접속 때와 30초마다 `minecraft:music.*` 를 멈춘다(데이터팩 `gave_env` 는 고치지 않음). 시험 훅 `/gave 시험 음악 <이름> [보기 | 곡 <키> | 단계 <낮음|중간|높음|자동> | 긴장 <0..1|자동> | 기록 [on|off] | 끔 | 켬 | 다시]`.

`/gave 상태` 의 `mobs=` 는 대기실 우리 개체를 뺀 수, 우리 개체는 `cage=` 로 따로 센다(설정 cage 가 꺼져 있으면 늘 0).

## 시험 도구(여러 에이전트가 같이 쓸 때)

- 따로 컴파일: `python -X utf8 tools/compile_wip.py --name <영역>` 은 진짜 소스에 `build/wip/<영역>` 을 덮어 `build/<영역>/Gave.jar` 를 만든다. `--promote` 는 통과하면 wip 파일을 진짜 자리로 옮긴다. `--real` 은 진짜 트리만으로 `build/real/Gave.jar`. 진짜 트리를 1분 넘게 깨진 채로 두지 않는다.
- 따로 컴파일(`tools/compile_wip.py`): 2026-11-12부터 javac 를 동시에 셋까지만 돌린다(`build/locks/javac-1..3.lock`, 힙 1.5G). 작업자 스물 넘게 동시에 컴파일하자 메모리가 몰려 페이지 파일이 커지고 C: 가 몇 GB 줄었다.
- 게임 안 시험: `python -X utf8 tools/ingame.py --name <영역> --scenario tools/scenarios/<대본>.json [--second-user Bishop --second-scenario tools/scenarios/idle.json] [--fresh-world] [--keep-pack]`
  - 길 둘(2026-11-12부터): 슬롯 9 서버(게임 26290, RCON 26291, 팩 8299, 월드 `runtime-9/gave_plaza`)나 슬롯 8 서버(26280, 26281, 8298, `runtime-8/gave_plaza`) 중 먼저 비는 쪽을 켜고(힙 2G) 시험 클라 대본을 돌린 뒤 끈다. 잠금은 길마다 운영체제 잠금 하나(`build/locks/ingame.lock` 이 슬롯 9, `ingame-8.lock` 이 슬롯 8, 누가 쥐었는지 `ingame.owner.json`, `ingame-8.owner.json`, 최대 6시간 기다림). `runtime-8` 이 없으면 `runtime-9` 를 월드, 기록 빼고 복사하고 안개 데이터팩을 깐 새 월드로 시작한다. 시험 클라 자리는 `build/locks/seat-1.lock`, `seat-2.lock` 을 판 내내 쥔다(PC 전체 2대, 다른 세션 클라도 셈). 실행 중 서버 기록은 `build/server-<슬롯>.log`, 끝나면 `build/<영역>/server_<번호>.log` 로 복사.
  - 팩은 실행마다 `build/<영역>/Gave-pack.zip` 으로 새로 묶고(`--keep-pack` 이면 있는 것 씀) 서버에 `-Dgave.packDir=build/<영역>` 으로 준다. `GV_PACK_SPLIT=1` 이면 둘로 나눠 `build/<영역>/Gave-sound.zip` 도 만들고 서버가 같은 폴더에서 둘 다 보낸다(위 '팩 둘'). 없으면 지금처럼 하나.
  - PC 전체 시험 클라 2대 한도(다른 프로젝트 것 포함, `--quickPlayMultiplayer` 자바 수)를 지키고, 끝나면 이 슬롯 시험 클라(gameDir 에 `gave-client-9` 가 든 것만)를 끈다. 좀비런 클라(`zombierun-client-9`)는 건드리지 않는다.
  - 시험 클라 감싸개는 Windows 작업 개체(KILL_ON_JOB_CLOSE, 이름 `gave-ingame-*`)에 넣어 ingame.py 가 갑자기 죽어도 클라가 함께 꺼진다. 시작 때 잡은 슬롯에 남은 자기 서버가 있으면 먼저 끄고, 남이 포트를 쥐고 있으면 월드를 건드리지 않고 멈춘다(`GV_SLOT=<슬롯> bash tools/test_server.sh stop` 안내).
  - 클라가 팩을 받은 뒤 5초 안에 꺼지면(0xC0000005 등) 기록을 사진 폴더로 옮기고 다시 띄운다(3번까지).

## 실서버(사용자 표준: 25565, 팩 8088, 바탕화면 bat)

- 만들기와 고치기: `python -X utf8 tools/make_live.py`. `live/` 폴더(서버 파일, `server.properties`: 25565, online-mode=true, enforce-secure-profile=false, accepts-transfers=true, 화이트리스트 끔, RCON 끔), 안개 데이터팩, 최신 `build/Gave.jar` 를 넣고 바탕화면에 `게이브_25565.bat`(CP949, CRLF)을 쓴다. 월드는 건드리지 않는다(`--fresh` 를 주면 월드를 지워 다음 켤 때 새로 지음). 25565 가 켜져 있으면 아무것도 바꾸지 않고 멈춘다.
- 같이 넣는 플러그인: KAKC 2.0.0(`totalwar/kakc/build/KAKC-2.0.0.jar`, 영어 자판으로 친 한글 자동 변환 `/kakc 모드 1` + 채팅 신고 차단). `make_live.py` 가 `live/plugins` 에 복사한다. 2026-11-11 실서버를 켜서 Gave, KAKC 둘 다 읽히는 것 확인.
- 켜기: 바탕화면 `게이브_25565.bat`. 켤 때 `build/Gave.jar` 를 `live/plugins` 로 복사하므로 플러그인을 다시 빌드한 뒤에는 bat 만 다시 켜면 된다. 판 시작은 게임 안에서 `/gave 시작`(운영자는 서버 창에서 `op <닉네임>`).
- 팩: 실서버는 `build/` 의 두 팩(모습 `Gave-pack.zip`, 소리 `Gave-sound.zip`, 위 '팩 둘')을 읽는다(`live/` 로 복사하지 않음). bat 는 `-Dgave.packRepo=tinymita2-pixel/gave-pack` 으로 팩마다 깃허브 릴리스 `pack-<그 팩 sha1 앞 12자리>` 를 먼저 찾고, 없는 팩만 이 PC 의 8088 포트(`/pack.zip`, `/sound.zip`)로 보낸다(다른 PC 에서 들어오려면 공유기에서 25565, 그리고 팩을 이 PC 에서 보낼 때는 8088 도 연다). `make_live.py` 는 두 팩이 어긋나 있으면(나눈 모습 팩만 있음, 하나로 묶은 팩 옆에 옛 소리 팩) 멈춘다.
- 깃허브에 올리기: `python -X utf8 tools/upload_pack.py --public`(`--public` 없이는 올리지 않음, `--dry-run` 은 아무것도 올리지 않고 깃허브에 묻지도 않고 할 일만 찍음, `--dir <폴더>` 로 다른 폴더의 팩). 팩마다 자기 릴리스 `pack-<그 팩 sha1 앞 12자리>` 에 파일 이름 그대로(`Gave-pack.zip`, `Gave-sound.zip`) 올리고, 이미 같은 태그가 있으면 그 팩은 건너뛰고(릴리스는 있는데 파일이 없으면 그 파일만), 올린 뒤 팩마다 다시 받아 sha1 을 맞춰 본다. 팩을 고쳐 다시 묶을 때마다 돌린다(바뀐 팩만 새 태그). 소리 팩이 없으면(하나로 묶은 옛 꼴) 모습 팩 하나만 올린다. 2026-11-11 사용자 결정("그대로 올려")으로 공개 저장소 https://github.com/tinymita2-pixel/gave-pack 에 올렸다(릴리스 `pack-ddb6dbfca1a7`, 22.8MB). 팩에는 _Gave 스킨 얼굴과 출처가 확인되지 않은 총소리(47개 중 45개)가 그대로 들어 있고, `CREDITS.txt` 맨 위 알림과 저장소 README 에 그 사실과 '권리자가 요청하면 내린다'를 적었다. 본인 동의 여부는 확인된 바 없어 적지 않았다.
