# 게이브 게임 안내

죽으면 의식이 있는 채로 게이브(_Gave 얼굴 괴물) 몸에 갇힌다. 살아남은 사람들은 트럭을 타고 우주선이 있는 발사장으로 달아난다.
20~30명이 트럭 둘레에서 사방 360도로 몰려오는 떼를 막으며 35라운드를 건너는 협동 생존 게임이다. 아주 어렵다.

## 조작

| 키 | 하는 일 |
|---|---|
| 우클릭 누르고 있기 | 쏘기 |
| 좌클릭 | 돕기(쓰러진 동료 일으키기 3초, 붙은 게이브 떼기, 보급 상자, 연타로 빠져나오기), 트럭 상점, 길 표지판 |
| 웅크리기 | 듣기(가까운 게이브 속 소리), 조준경 |
| Q | 재장전 |
| F | 수류탄 |
| 1, 2, 3 | 주무기, 권총(탄 무한), 소모품. 투표 창이 열려 있으면 그 번호 길에 한 표 |

## 판 흐름

| 라운드 | 막 | 일 |
|---|---|---|
| 1~10 | 1막 마른 길(해 질 녘) | 10 보스 B1 산더미 |
| 11~20 | 2막 젖은 벌(비, 밤) | 20 보스 B2 하늘 덮는 |
| 21~30 | 3막 재의 땅(한밤, 검붉은 하늘) | 30 보스 B4 지평선 |
| 31~35 | 4막 발사장(새벽 전 칠흑) | 31~34 우주선 건조(33 은 보스 B3 에워싸는 게이브와 함께), 35 보스 B5 모두의 게이브 → 탑승, 발사, 엔딩 |

- 막이 넘어갈수록 땅, 하늘, 소리, 게이브가 어두워진다. 한 판에 모든 종류의 게이브가 나온다.
- 라운드마다 종류가 다르다(보통, 추격전 같은 특수 라운드). 이름 띠가 위에 뜬다.
- 쉬는 시간은 상점. 짝수 라운드 뒤에는 길 투표와 이동이 붙는다.
- 지면(모두 쓰러지거나 트럭이 터지면) 채팅에 '다시 하시겠습니까? [여기를 누르기]'가 뜬다. 투표다: 판이 끝나는 40초 안에 이 판에 든 접속자의 과반이 누르면(나간 사람은 안 셈) 모두 상점 앞에 다시 서고, 20초 준비 뒤 진 라운드부터 다시 한다. 총, 증강, 강화, 돈, 트럭 부품은 그대로, 터진 트럭은 그 라운드를 시작할 때의 체력으로. 다시 한 판은 최고 기록에 들어가지 않는다(처음 시도까지만 기록).

## 트럭

- 가운데 트럭이 상점이다. 쉬는 시간에는 원 안 어디서나, 라운드 중에는 트럭 곁에서만 열린다.
- 트럭에 체력이 있다(핫바 위 막대). 게이브가 트럭을 문다. 0 이 되면 서 있는 사람이 있어도 판이 끝난다.
- 상점 '트럭 수리'는 누른 사람이 먼저 내고 모두의 몫에서 돌려받는다. 4막에서는 트럭 막대가 우주선 막대로 바뀐다.

## 길 투표(2라운드마다)

- 트럭 앞에 표지판 셋이 내려온다. 15초 안에 1, 2, 3 키나 표지판 좌클릭으로 고른다. 표가 많은 길로 간다.
- 갈래마다 다음 스테이지가 다르다(보상, 정비, 함정, 위험 등). 보스 앞 길목은 숨 고르기, 질주, 무장.
- 30라운드 뒤에는 투표 없이 발사장으로 들어간다.

## 발사장(31~35)

- 건조 지점 셋(연료 펌프, 발전기, 발판)의 원 안에 게이브보다 사람이 많으면 건조가 돈다. 위 금빛 막대가 라운드마다 25% 찬다.
- 35라운드에 B5 가 일어선다. 잡으면 탑승, 초읽기, 발사, 엔딩 글 다섯 줄, 그 판 사람 이름 크레딧.

## 쓰러짐과 죽음

- 체력 0 이면 쓰러진다. 출혈 12초 안에 동료가 좌클릭 3초로 일으킨다(공짜).
- 출혈이 끝나면 죽는다. 라운드가 끝나 쉬는 시간이 되면 죽은 사람, 갇힌 사람, 쓰러진 사람 모두 상점 앞에서 체력 가득으로 공짜로 돌아온다(돈 손실 없음).
- 라운드 중에 빨리 돌아오려면 다른 사람이 트럭 상점 '꺼내기' 줄에서 돈을 낸다(여럿이 나눠 낼 수 있음, 꺼내질수록 비쌈). 다 못 모은 채 쉬는 시간이 되면 낸 돈은 돌려받는다.
- 죽은 동안 카메라는 내 얼굴을 한 게이브를 따라간다. 동료가 그것을 잡으면 꺼내는 값이 내려간다. 죽어도 길 투표는 한다.
- 먹혔으면 그 게이브를 잡는 순간 풀린다. 못 구해도 쉬는 시간에 돌아온다.
- 35라운드 B5 를 잡은 뒤 발사 차례에는 공짜 부활이 없다(꺼내기만).

## 돈

- 게이브를 잡으면 그 돈의 70% 는 판에 든 모두가 똑같이 받고, 30% 는 때린 사람들이 때린 만큼 받는다. 둘 이상이 함께 잡으면 때린 사람들이 10% 를 더 받는다.
- 돈은 1초에 한 번 들어온다. 남이 잡아도 오르고, 쓰러지거나 죽어 있는 동안에도 받는다. 1분 넘게 게이브를 맞히지도 돕지도 않으면 모두의 몫은 못 받는다(판 시작과 들어온 뒤 1분은 받는다). 아무도 안 맞혔는데 저절로 죽은 게이브(제가 터짐, 깔림, 불길)는 돈이 안 된다.
- 쓰러진 동료를 일으키거나 붙은 게이브를 떼어 주면 수당이 나온다(같은 동료는 라운드에 한 번, 한 사람이 여섯 번까지). 트럭 수리에 낸 돈은 실제로 고친 만큼, 꺼내기에 낸 돈은 다 모두의 몫에서 먼저 돌려받는다.
- 보스를 잡으면 모두 45 x 라운드 원. 전투 길을 넘기면 모두 1U, 험로는 5U(U = 그 라운드 무기 상자 값).
- 늦게 들어온 사람은 다른 사람들이 그 판에서 번 돈 평균의 70% 를 받고 시작한다.

## 상점

- 무기 상자 줄(셋째 줄): 모든 종류 상자 하나와 갈래 상자 여덟. 갈래 상자는 그 갈래 종류 가운데 하나를 뽑고 모델은 그 종류 안에서 고르게, 등급은 라운드가 높을수록 좋다(모든 상자 같음). 뽑은 총은 '새로 뽑은 무기' 칸에 놓이고, 그 칸을 누르면 바꾸고 지금 총을 누르면 버린다. 놓여 있는 동안 상자 줄은 잠긴다.

| 상자 | 드는 종류 | 1라운드 값 |
|---|---|---|
| 무기 | 아래 모두(무기 211모델) | 130 |
| 권총 | 리볼버, 기관권총, 쌍권총, 소음기 총 | 90 |
| 기관단총 | 기관단총 | 110 |
| 소총 | 소총, 점사 소총, 지정사수 소총, 머스킷 | 130 |
| 기관총 | 경기관총, 미니건 | 155 |
| 샷건 | 산탄총, 자동 산탄총, 쌍발 산탄총 | 125 |
| 저격 | 저격소총, 볼트액션 소총, 대물 저격총 | 145 |
| 특수 | 화염방사기, 냉동총, 전기총, 광선총, 레일건, 복합궁 | 170 |
| 폭발 | 유탄발사기, 로켓 발사기 | 180 |

- 값은 라운드마다 5% 오르고, 갈래 상자는 그 갈래를 산 횟수마다 1.1배(갈래마다 따로, 모든 종류 상자는 안 오름). 공짜 상자 표는 어느 상자에나 쓴다.
- 그 밖에 강화, 탄약, 소모품, 스탯(첫째 줄), 증강 뽑기.
- 자동 탄약(증강 칸): 한 번 사면 판 내내, 트럭 곁에서 탄이 떨어지면 저절로 산다.
- 트럭 수리, 트럭 부품(보상으로 받은 차례가 있을 때), 꺼내기.

## 운영자

명령 `/gave`(또는 `/게이브`), 권한 `gave.op`.

| 명령 | 하는 일 |
|---|---|
| `/gave 시작` | 판 시작 |
| `/gave 중지` | 판을 멈추고 대기실로 |
| `/gave 상태` | 상태, 라운드, 남은 게이브 수 |
| `/gave 자동 on` 또는 `off` | 대기실에 minPlayers 명이 차면 30초 뒤 저절로 시작 |
| `/gave 원정 on` 또는 `off` | 원정(트럭이 있는 방식: 트럭, 길 투표, 이동, 발사장)을 켜고 끔. 끄면 트럭 없이 중앙 원에서 웨이브만 막는 옛 방식. 대기실에서 치면 바로 바뀌고(트럭과 길이 서거나 사라짐), 판 중에 치면 그 판은 그대로 두고 대기실로 돌아가면 바뀜. 설정 `trip.enabled` 에 남음. 인자 없으면 지금 값 |
| `/gave 팩` | 리소스팩을 다시 보냄 |
| `/gave 웨이브 <n>` | n 라운드로 건너뜀(기록에 안 남음) |
| `/gave 데미지 [배율]` | 게이브(보스 포함)가 사람에게 주는 피해 배율. 기본 1, 2 면 2배, 0.1~10. 바로 먹고 설정 `damageMul` 에 남음. 인자 없으면 지금 값 |
| `/gave 공격력 [배율]` | 사람이 게이브(보스 포함)에게 주는 피해 배율(총, 폭발, 불, 냉동, 번개, 증강, 트럭 장치). 기본 1, 0.1~10. 바로 먹고 설정 `playerDamageMul` 에 남음. 인자 없으면 지금 값 |

설정: `plugins/Gave/config.yml`(실서버 `live/plugins/Gave/config.yml`, 기본값 `plugin/src/main/resources/config.yml`). 원정은 `trip.enabled`(기본 켬, 손으로 고치지 않고 `/gave 원정 on|off` 로 바꿈: 서버를 다시 켜지 않아도 됨), 크레딧 `trip.credits`, 발사 뒤 이어 가기 `trip.afterLaunch`(기본 끔), 난이도 `difficulty`, 보스 체력 배율 `bossHp`(기본 0.6), 보스가 아닌 게이브 체력 배율 `mobHp`(기본 0.75), 사람이 버는 돈 배율 `moneyMul`(기본 1, 행사용. 돌려받는 돈에는 안 곱함). 바꾼 뒤 서버를 다시 켠다. 빌드와 배포는 `docs/운영.md`.
