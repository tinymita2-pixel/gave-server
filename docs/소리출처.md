# 받은 효과음 출처(2026-11-12)

사용자: "사운드가 최소 60개 이상 있어야 해, 브금이든 효과음이든", "거대한 절망감이라든지 압도감이 느껴지면 좋겠어", 2026-11-11 "합성하지 말고 어디서 다운해 와". 그래서 효과음도 합성하지 않고 내려받는다. 배경 음악 출처는 `docs/브금출처.md`.

## 규칙

- 팩이 공개 저장소(tinymita2-pixel/gave-pack)로 배포되므로 CC0 또는 CC BY 만. NC, ND, SA, 출처 불명 '무료' 모음, 가입이나 로그인이 필요한 곳(freesound 등)은 쓰지 않는다. 받기 전에 글 페이지의 라이선스 칸을 직접 읽는다.
- 받은 파일은 새 빈 폴더(작업 임시 폴더)에 받아 zip 목록만 읽고(풀지 않고 실행하지 않음) 소리 파일만 `ref/sfx/<묶음>/` 로 꺼낸 뒤 zip 은 지운다. 파일 이름만 소문자와 `_` 로 바꾸고 내용은 받은 그대로. 묶음마다 `_info.json`(글 페이지, 받은 주소, 라이선스와 주소, 페이지에서 본 라이선스 글, 만든 사람, 받은 날, 원본 zip 과 꺼낸 파일마다 sha256, 원래 이름).
- 목록 `data/sfx_lib.json`: `python -X utf8 tools/gabe/audio.py lib` 가 원본을 풀어(ffmpeg) 재고 태그를 붙여 새로 쓴다(손으로 고치지 않음, 원본이 `_info.json` 의 sha256 과 다르면 멈춤). 지금 1252개, 묶음 78, 태그 157(2026-11-12 aud_trip 이 46 묶음을 더함, 옛 921 항목과 그 뒤 324 항목은 바이트까지 그대로). 항목: `id`(`<묶음>/<이름>`), `file`, `pack`, `tags`, `dur`(초), `ch`, `sr`, `bytes`(원본 크기), `rms_db`, `loud_db`(가장 큰 0.4초 RMS), `peak_db`, `low`(150 Hz 아래 에너지 몫), `centroid`(Hz), `sha256`, 긴 녹음은 `parts`(소리 덩어리 [시작, 끝] 초, 아이디 뒤 `#번호` 로 씀).
- 찾아보기: `python -X utf8 tools/gabe/audio.py find tag:roar`, `find "oga_zombies/*"`, `find "oga_snarls/*" parts`(덩어리 시각까지).
- 팩에 넣을 때 다듬기(`audio.prepare`): 자르기(덩어리, start, end), 앞뒤 무음 자름, 가장 큰 0.4초 크기를 맞춤(level dBFS, 피크 -1 아래), mono(자리 소리), libvorbis q4. 높이는 sounds.json 의 pitch 로(파일은 원래 높이). 8초 넘는 것은 stream.
- CC BY 묶음(Little Robot Sound Factory 와 원정 8 묶음: oga_engine_heavy, oga_tire_skid, oga_rocket_launch, oga_jet_takeoff, oga_thunder_close, oga_slide_whistle, oga_engine_hum, oga_facility_siren)은 팩 `CREDITS.txt` [7b] 에 저작자 표시가 꼭 들어가야 한다. [7b] 는 `tools/gabe/audio.py credit_lines()` 가 만들고 `tools/make_bgm.py music_credit_lines()` 가 [7] 뒤에 붙여 돌려준다(`build_props.write_credits` 가 이 함수를 부름, `make_bgm.py` 를 돌리면 층의 CREDITS.txt 에서도 [7], [7b] 를 바로 고침. [8] 부터는 무기 담당 절이라 번호를 피함). CC0 묶음도 고마움으로 적는다.

### GCB 총 세 자루(`tools/props/gcb_sounds.py`)

- 다른 서버(GCB)에서 옮긴 총 세 자루(마스티프, 렘페이지, 볼트 피스톨)의 총소리와 재장전 부품 소리다.
- 그쪽 서버에서 쓰던 소리 파일은 권리가 확인되지 않아 이 저장소와 팩 어디에도 넣지 않았다. 그 소리의 파형을 재서(층이 시작하는 시각, 반 옥타브 띠마다 크기 곡선, 첫 충격의 저역 출렁임) 얻은 숫자만 `tools/props/gcb_sounds.py` 의 표에 적었고, 소리는 그 표로 새로 만든다: 띠마다 거른 잡음에 감쇠 곡선 몇 개를 곱한 것과 감쇠하는 사인 몇 개. 원본 표본을 잘라 쓰거나 원본 스펙트로그램을 틀로 쓰지 않는다.
